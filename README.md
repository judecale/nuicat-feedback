# nuicat feedback

Bug reports and feature requests for [nuicat](https://nui.cat) —
a speech-to-text daemon for Linux.

- **Bug report or feature request:** open an issue using the templates below
- **Quick questions and discussion:** join the [Discord](https://discord.gg/UZfbFv9a9g)
- **Contact:** hey@nui.cat
- **Docs:** https://nui.cat/docs

> This repo contains no code. The nuicat source is closed-source and private.
